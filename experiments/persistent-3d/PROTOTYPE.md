# 阶段 1：最小原型合同

状态：设计定义完成，尚无可运行原型，所有验收项待验证。

范围：Hero → 花园 → 沙漠 → 海洋 → Core 第一次结构展开。选择三个生态，因为仅一个生态不能检验跨境连续性；两个接缝足以揭露重复模板、纹理交接和滚动重置的问题。丛林与地狱的正式内容仍在稳定站，本原型不意味着删除它们。

本阶段不做管理层全量整合、完整成员系统迁移、三维流体求解、片尾影片改版、正式入口替换或发布。

## 先比较模型，再编排镜头

先比较 README 中 A/B 两种模型的正面、左右 30°、侧面厚度、局部展开和圆润节点形态。比较必须使用实际几何，不用概念图冒充可渲染模型。选定剪影后只保留一条主案。

Core 根节点保持身份，结构件使用稳定 ID。模型拆解与节点采样位置是确定的；同一个滚动位置在反向浏览、刷新恢复时应得到同一姿态。低档减少几何细分和材质成本，不删除第一次展开。

## 五个镜头状态

这些是构图目标与归一化时间，不是已经实现的画面。时长最后根据实际可读性调整，不强制自动播放。

| 进度 | 画面 / Camera | 与原内容的实际关系 | 手机设计 |
| --- | --- | --- | --- |
| 0–0.15 · 身份 | 正面偏航约 10°，2ⁿ 居中，下缘嵌在原地貌；微旋转露出深度 | 前景真实遮住 Core 下半部，延续 v1 开场；禁止只悬浮在背景上 | 主体控制在上中部，提示留在安全区；轻档可在短暂微动后停帧 |
| 0.15–0.35 · 出发 | 镜头小幅前进并向花园侧转移，Core 离开遮挡但不突然缩成页眉图标 | 花园从 Hero 的同一片绿色扩展而来，文案留在前景阅读层 | 以横移和大小变化为主，减少透视推进；原生手势直接决定状态 |
| 0.35–0.58 · 并肩 | Core 稍靠右，结构保持完整；花园变沙漠时同一件边缘留在画面 | 先前环境色逐渐让位，结构受光与遮挡共同改变；不是硬切背景 | Core 和正文上下分区，文字不依赖 3D 锚定；过渡不靠细线拼接 |
| 0.58–0.82 · 方向 | 进入海洋，视点渐接近结构连接处；先停止整体旋转，再打开局部 | 配合现有探索、判断与协作的文案，揭示内部仍有稳定连接 | 使用较小位移与更长的稳定阅读段；保证至少一次前后遮挡变化 |
| 0.82–1 · 揭示 | 结构展开少量距离、相机后退露出整体，出现冷蓝内部节点 | 回答“是什么让整体保持连接”，为后续人物章节留下明确入口 | 保留同一展开事件，减少细分与装饰粒子；终点停帧，可反向收拢 |

所有境界接缝共享前后状态，位置、缩放、旋转无跳变。不能每节重新初始化 camera 或模型。单纯 opacity 淡入淡出不算完成空间关系。

## 帧与交接合同

建议原型模块分为模型几何、纯状态采样、滚动适配、渲染与生命周期；这不是要求重构正式 app.js。

滚动适配输出 `chapterId / chapterProgress / direction / viewport / inputProfile / reducedMotion`，由唯一帧调度器采样。桌面和手机具有相同语义状态，但相机曲线与阅读区域不同。章节坐标在初始化、实际尺寸变化后缓存，不在每帧读取全部 DOM 布局。

后续液滴交接预留 `screenCenter / projectedRadius / color / nodeIds / handoffWeight`。交接时 3D 投影靠近既有二维构图：节点先移到目标位置、材质接近液滴，再以有界短交叠移交；母滴接管后 Core 停绘。反向滚动由同一权重恢复，不靠一次性回调猜测状态。该接口还需阶段 2 实证，不能提前称无缝转换已解决。

reduced-motion：静态 Core + 同样的正文与章节可达性，禁用空间推进与自动旋转。WebGL 不支持、初始化失败或恢复失败：不阻塞正文，保留正常导航与静态字标/地貌；不得留下空白加载页。

## 初始性能预算

下列为实验门槛，可根据实测作有理由的收紧；不能为通过验收悄悄放宽。数字是预算，不是当前结果。

| 项目 | 桌面初档 | 移动默认档 / 轻档 |
| --- | --- | --- |
| Renderer / context | 1 个 | 1 个；内容模式 0 个 |
| DPR | 上限 1.5 | 默认 1，轻档 0.85；只在稳定边界切换 |
| Core 几何 | ≤20k triangles | ≤8k / ≤4k；保留同一剪影 |
| 3D draw calls | ≤35 | ≤20 / ≤12 |
| Core 材质 | 少量不透明材质，可预烘焙照明 | 不使用实时 transmission、阴影贴图或屏幕空间反射 |
| 后处理 | 第一版 0 | 0 |
| 同时驻留生态纹理 | 当前与相邻，按预算预取 | 最多当前 + 下一境；上一境可重新取得 |
| 装饰粒子 | 第一阶段仅必要内部节点 | 不做满屏粒子；节点低细分实例化 |
| WebGL 资源估算 | ≤64 MiB | ≤32 MiB，不包含 DOM/旧 Canvas/视频；总成本另测 |
| 新增 Core 几何文件 | 压缩传输 ≤150 KiB | 同一上限；程序化几何则计入 JS |
| 新增首段 3D JS + 模型 | gzip/Brotli 传输合计 ≤350 KiB | 同一上限，不使用大字体包 |
| 原型初始关键传输 | 含预览图与 3D 关键资源 ≤1 MiB | 同一上限；不同时等待全部五境图 |

原有 PNG 不覆盖，实验使用另存的适配尺寸/格式副本或分阶段加载。纹理 mipmap、重复上传与缓冲计入估算。浏览器没有通用可靠的可用显存/电池温度 API，不用伪造的“显存测量”充当验收。

默认质量从保守档开始，累计约 2 秒有效前台动画样本再决定降低像素成本；至少冷却 5 秒，避免档位抖动。不要仅靠屏幕宽度判断性能。后台取消调度；返回直接采样当前位置，不补播后台时间；页面退出释放资源；遇上下文丢失显示回退，恢复成功后重建一次，否则保持内容模式。

## 验收：全部硬门槛通过才扩展

| 检查 | 方法 | 通过标准 |
| --- | --- | --- |
| 视觉增益 | 与同范围 v1 对照，统一屏幕、文字和环境；保留同位置画面/短录屏 | 能明确指出深度遮挡、空间接缝、结构揭示三项收益；仅更亮/更多特效不通过 |
| 2n 辨识 | 去掉页面角落字标，看正面与左右 30° 实际模型图；至少 3 位熟悉 2n 的观察者 | 至少 2 位无需提示能辨认 2n，并能跟踪展开前后的同一主体；未收集反馈则待验证 |
| 内容关系 | 隐藏 Core 做对照，再看完整版本 | 花园进入、跨境、海洋展开各自有不同内容作用；不是同一套卡片轮播 |
| 连续性 | 慢滑、快速越过两境、反向、章节跳转各重复 5 次 | 无黑帧、模型重置、丢状态；停滑后最终状态一致；正文不等待动画解锁 |
| 桌面流畅 | 固定 60Hz 环境，连续前台活动 60 秒，记录 rAF 间隔与主线程工作 | 活动样本 p95 帧间隔 ≤22 ms；没有可归因于实验的重复 >100 ms 停顿 |
| 手机流畅 | 至少一台真实 iPhone Safari，以及一台较旧 iPhone 或中低档 Android；同场景跑两遍 | 活动样本 p95 ≤40 ms，无重复 >100 ms 卡顿；滚动和文字可读；不把 CPU 节流当真机 |
| 负载持续性 | 真机持续正反浏览 5 分钟，含两次后台返回与旋转 | 不重载、不丢失 context；末段同场景帧时间不比初段恶化超过 20%；无持续资源增长趋势 |
| 首屏 | 冷缓存，固定 9 Mbps 下行 / 150 ms RTT，5 次取中位数，并与 v1 同条件比较 | 正文/静态 Hero 的 LCP ≤2.5 秒且不比 v1 增加 >200 ms；首个 3D 可见帧 ≤3 秒，不阻塞阅读 |
| 生命周期 | 后台 30 秒、BFCache 返回、横竖屏各 5 次、context lost/restore | 回到相同章节语义进度、无重复 Canvas/事件监听，恢复失败可读 |
| 可访问性与失败 | reduced-motion、JS 失败、WebGL 失败、键盘与缩放 | 正文、章节跳转、返回入口完整，未加载 3D 也能使用 |

rAF 间隔、JS 执行耗时、GPU 时间不是同一指标；分别标注，不把低 JS 耗时当高 FPS。30fps 轻档采样要按实际绘制节奏解释，不能通过丢弃慢帧“优化”报告。记录设备、系统、浏览器、提交、网络条件、质量档和测量时段。

没有真实 iPhone 结果时，可以完成和保存原型，但不能判定阶段 1 通过，也不能开始全篇整合。最多两轮有明确目标的修正后仍不满足辨识度、连续性或移动负载门槛，则建议停止扩展，保留 v1。
