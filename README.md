# 2n Site v1

Static Cloudflare Pages-ready prototype.

## Deploy
Upload this folder/repository to GitHub and connect it to Cloudflare Pages.
For a plain static deployment, no build command is required; publish directory is `/`.

## Main files
- `index.html`
- `style.css`
- `app.js`
- `assets/half-year.mp4`
